## Maker Faire

Maker Faire is a similar exhibit style event as Imagine RIT with more focus on engineering and makers space with organizations coming from outside of the RIT. This event is in the fall semester around mid-November.

This event is really good for getting a practice at demoing our project and getting used to talking about this capstone project.

For more information on application go to [their website](https://rochester.makerfaire.com/)
Application filled out for fall 2025 could be found [here](</makerfaire/2025/2025 Fall Application Form.md>)
